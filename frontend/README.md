# BD Lab frontend

React + TypeScript + Vite theo Stitch. Mặc định VITE_DATA_SOURCE=api, đọc/lưu backend/PostgreSQL.
VITE_DATA_SOURCE=mock giữ chế độ Giai đoạn 2 (chỉ trong phiên).
Xem README gốc và docs/phase-3.md. Chạy npm.cmd run dev từ root sau khi database sẵn sàng.
Không đặt secret trong biến VITE_*. PDF và thông tin chỉ gửi backend local khi API mode.
