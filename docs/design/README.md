# Thiết kế tham chiếu Stitch

Nguồn: dự án BD Lab Management System, ID `4642043071957094690`.
Các HTML và PNG trong `stitch/` là bản tham chiếu thiết kế, không được thực thi bởi ứng dụng.

- screen-0: Tiếp nhận mẫu.
- screen-1: Sổ nhận mẫu.
- screen-2: Kiểm tra biên bản.
- screen-3: Tổng quan.

Frontend hiện thực bằng React components và CSS local, dùng font Inter local.
Giữ nhận diện cam, sidebar xám, thẻ chỉ số, bảng và workspace PDF/dữ liệu của Stitch.
Thay nội dung mẫu bằng dữ liệu hoàn toàn giả lập; không lấy thông tin khách hàng từ thiết kế.
Các hành động đồng bộ, xác nhận và cấp mã chính thức không thực hiện trong Giai đoạn 2.
