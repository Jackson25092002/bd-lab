# AI Integration

Module độc lập dành cho Microsoft AI Builder qua Power Automate (Giai đoạn 4).
Chưa có endpoint callback hay gọi dịch vụ AI. Callback tương lai phải có xác thực.
Giữ dữ liệu OCR gốc và dữ liệu chỉnh sửa riêng; không suy đoán trường không đọc được,
không tự xác nhận hồ sơ. Không dùng Gemini hoặc Azure AI Document Intelligence.
